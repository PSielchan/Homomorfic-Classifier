# Projekt Kryptografii - Szyfrowanie Homomorficzne

Jak uruchomić notebook `krypto_projekt.ipynb`.

## Wymagania i Instalacja

1. **Python:** Projekt wymaga Pythona w wersji **3.11.5+**.
2. **Pliki:** Upewnij się, że plik `krypto_projekt.ipynb` oraz `requirements.txt` znajdują się w katalogu roboczym.
3. **Stworzenie środowiska wirtualnego (zalecane):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux / macOS
   .\venv\Scripts\activate  # Windows
    ```
    Instalacja zależności:
    ```bash
    pip install -r requirements.txt
    ```
    
## Uruchomienie

Uruchom plik w środowisku Jupyter Notebook i wykonaj jego komórki.
